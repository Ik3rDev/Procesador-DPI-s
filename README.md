# 📄 Procesador Documental (DPI y Recibo de Luz) - v2.2.1

Aplicación web cliente local para el procesamiento, recorte poligonal de perspectiva y extracción de datos vía IA para documentos de DPI y Recibos de Luz.

---

## 🚀 Características
- 🎴 **Procesamiento de DPI:** Carga e integración del anverso y reverso en un documento único.
- 📐 **Ajuste de Perspectiva:** Corrección mediante recorte por polígonos/puntos con OpenCV.js.
- 🤖 **Extracción Automática (OCR / IA):** Lectura e identificación de CUI/DPI y Nombre completo.
- 📋 **Generación de Memos:** Copia rápida de datos formateados para bloc de notas.
- 💡 **Recibo de Luz:** Módulo independiente para ajuste y exportación a PDF.
- 🔒 **Privacidad Local:** Procesamiento en memoria local sin almacenamiento permanente no autorizado.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5 / CSS3 / JavaScript (ES6+)**
* **Tailwind CSS** (Interfaz gráfica)
* **OpenCV.js** (Transformación de perspectiva)
* **jsPDF** (Generación de archivos PDF)
